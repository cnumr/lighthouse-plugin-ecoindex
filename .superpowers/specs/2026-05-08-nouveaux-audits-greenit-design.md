## 2. Script `generate-refs-urls.ts`

**Fichier** : `scripts/generate-refs-urls.ts`

### Comportement
- Lit la liste des IDs RWEB depuis un tableau interne au script (tous les IDs utilisés par les audits)
- Pour chaque ID × locale (`fr`, `en`) : `GET https://rweb.greenit.fr/api/fiches/{id}?lang={locale}&version={version}`
- Génère `libs/ecoindex-lh-plugin-ts/src/audits/bp/refs-urls.ts`
- En-tête du fichier généré : `// Generated by scripts/generate-refs-urls.ts — RWEB version: X.Y.Z`
- Paramètre version : `--version X.Y.Z` (défaut : `latest`)

### Commandes npm
```json
"refs:update": "tsx scripts/generate-refs-urls.ts",
"refs:update:version": "tsx scripts/generate-refs-urls.ts -- --version"
```

### Structure du fichier généré
Les blocs `ecoindex.*` et `greenwebfoundation.*` restent hardcodés — seul le bloc `rweb.*` est régénéré.

## 3. Gatherer `BPGatherer`

### Fichier
`libs/ecoindex-lh-plugin-ts/src/gatherers/bp-gatherer.ts`

### Interface collectée (une seule `executionContext.evaluate`)
```ts
interface BPGathererResult {
  autoplaying: number          // <video autoplay> + <audio autoplay> + preload="auto"
  serviceWorkerActive: boolean // navigator.serviceWorker?.controller !== null
  canvasCount: number          // <canvas> dans le DOM
  inlineScripts: number        // <script> sans src (hors type="application/ld+json")
  inlineStyles: number         // <style> non-vides
  animatedElements: number     // éléments avec animation ou transition CSS actifs (getComputedStyle)
}
```

### Wiring obligatoire (4 fichiers)

1. **`src/gatherers/bp-gatherer.ts`** — classe `BPGatherer extends Gatherer`, méthode `getArtifact(passContext)`, pattern identique à `DOMInformations`

2. **`src/helpers/lhci/custom-config.ts`** — ajouter dans `artifacts` :
   ```ts
   import bpGatherer from '../../gatherers/bp-gatherer.js'
   // ...
   { id: 'BPGatherer', gatherer: { implementation: bpGatherer } }
   ```

3. **`src/types/index.d.ts`** — ajouter :
   ```ts
   export interface BPArtifacts extends Artifacts { BPGatherer: BPGathererResult }
   export interface BPGathererResult {
     autoplaying: number
     serviceWorkerActive: boolean
     canvasCount: number
     inlineScripts: number
     inlineStyles: number
     animatedElements: number
   }
   ```

4. **Dans chaque audit BP qui utilise le gatherer** — typer `artifacts` comme `LH.Artifacts & BPArtifacts` et déclarer :
   ```ts
   requiredArtifacts: ['BPGatherer'] as (keyof UniversalBaseArtifacts | keyof ContextualBaseArtifacts | keyof GathererArtifacts)[]
   ```

> **Attention** : Le gatherer n'est enregistré que dans `custom-config.ts` (pas dans `plugin.ts`). Les audits qui n'ont pas besoin du gatherer (réseau, `MainDocumentContent`, `LinkElements`) ne déclarent pas `BPGatherer`.

## 5. Tests

### Stratégie
Aucun test existant n'est cassé : les nouveaux audits ont `weight: 0` et `verify-results.js` ne vérifie pas les audits BP.

### Nouvelle page de test
`test/test-pages/bp-violations.html` — déclenche intentionnellement les violations détectables sans réseau externe :
- `<video autoplay>` (RWEB_0106)
- `<canvas>` (RWEB_0055)
- `<style>` inline + `<script>` inline × 3 (RWEB_0042)
- `<img src="placeholder.gif">` (RWEB_0099)
- Pas de `<title>` ni `<meta name="description">` (RWEB_0011)
- `<embed src="doc.pdf">` (RWEB_0033)
- Éléments avec `animation: spin 1s infinite` (RWEB_0009)

### Mise à jour des vérifications
- Ajouter `bp-violations` dans `expected-results.json` avec `expectedBPAudits: { "rweb-0106-no-autoplay": 0, "rweb-0055-no-canvas": 0, ... }`
- Étendre `verify-results.js` : si `expected.expectedBPAudits` présent, vérifier `lhr.audits[id].score`
- Ajouter `http://localhost:3000/bp-violations` dans `URL_TO_PAGE_KEY` dans `verify-results.js`
- Ajouter l'URL dans `.lighthouserc.cjs` du test plugin-ts

### Audits réseau purement externes
RWEB_0059, RWEB_0084, RWEB_0081 passent à `score: 1` sur les pages de test locales (pas de CDN sociaux, HSTS absent sur localhost → comportement attendu documenté dans `expected-results.json`).
